# 실기 보행 정책 로그

상위 폴더는 모델·스케일 또는 실험 계열, 하위는 세션, `trial_*`는 반복 시험이다. 고정 명령을 입력해 실제 로봇에서 관측, 액션, 목표와 실행 피드백을 기록한다. CSV는 시간축을 따라 값을 검토할 때, JSON은 시험 조건과 요약을 확인할 때, NPZ는 관측·액션 배열을 재분석할 때 사용한다.

모델 비교는 같은 명령 구간을 맞춘 뒤 수행한다. 초기 자세, 액션 스케일과 제어 주기가 다르면 같은 정책이라도 직접 비교가 어렵다. [기록 절차](../docs/README.md)와 [수집 스크립트](../scripts/record_5090_v01_robot_trial.py)를 참조한다.
